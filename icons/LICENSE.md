# Icon assets

All SVG assets in this directory were created for this project. They use a
consistent `24x24` viewBox and a `1.875` unit stroke, inspired by the visual
language of [Lucide](https://lucide.dev) (ISC License), but the paths here are
original geometry, not copies of Lucide files.

If a future edit copies a path verbatim from Lucide, record the upstream name,
the Lucide version, and the ISC license text for that specific asset below.

## Files

| Asset | Origin | Note |
|---|---|---|
| `actions.svg` | Original | Monochrome action sprite; symbols consumed with `currentColor`. |
| `folder-empty.svg` | Original | Non-hidden directory, no children. |
| `folder-non-empty.svg` | Original | Non-hidden directory with children. |
| `folder-empty-hidden.svg` | Original | Dot-prefixed directory, dashed outline, no children. |
| `folder-non-empty-hidden.svg` | Original | Dot-prefixed directory, dashed outline, with children. |
| `file-txt.svg` | Original | `.txt`. |
| `file-md.svg` | Original | `.md`, `.markdown`. |
| `file-json.svg` | Original | `.json`. |
| `file-js.svg` | Original | `.js`, `.mjs`, `.cjs`, `.ts`, `.tsx`, `.jsx`. |
| `file-py.svg` | Original | `.py`. |
| `file-java.svg` | Original | `.java`. |
| `file-pdf.svg` | Original | `.pdf`. |
| `file-zip.svg` | Original | `.zip`, `.tar`, `.gz`, `.tgz`, `.7z`, `.rar`. |
| `file-image.svg` | Original | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.svg`. |
| `file-generic.svg` | Original | Unknown or missing extension. |
| `symlink-badge.svg` | Original | Overlay badge for `SymlinkDir` / `SymlinkFile`. |
